## 🔍 معايير الصيغ

| المعامل | الصيغة | أمثلة |
|--------|-------|--------|
| `date` | YYYY-MM-DD | 2026-03-22, 2026-12-31 |
| `start_time` | HH:MM | 10:00, 06:00, 23:59 |
| `end_time` | HH:MM | 18:00, 14:00, يجب > start_time |

---

## 📊 ما الذي يحدث

```
1. جلب بيانات المنتج
2. التحقق من نوع المتجر (regular فقط)
3. التحقق من صيغ التاريخ والأوقات
4. إنشاء سجل المزاد (السعر ينقل تلقائياً)
5. تحديث المنتج (is_auction = true)
```

---

## ❌ رسائل الخطأ المتوقعة

### متجر توبأب
```
❌ خطأ: لا يمكن تحويل منتج من متجر توبأب إلى مزاد
```

### صيغة تاريخ خاطئة
```
❌ خطأ: صيغة التاريخ غير صحيحة. المتوقع: YYYY-MM-DD
```

### وقت نهاية أقل من البداية
```
❌ خطأ: وقت النهاية يجب أن يكون بعد وقت البداية
```

## 🎯 النقاط المهمة

1. **السعر تلقائي** - لا تحتاج لإدخاله
2. **متاجر عادية فقط** - توبأب مرفوضة
3. **صيغ محددة** - التاريخ: YYYY-MM-DD، الأوقات: HH:MM
4. **معالجة أخطاء** - رسائل واضحة بالعربية
